# Vattenfallsmodellen

Innan agila metoder blev standard planerades de flesta projekt enligt vattenfallsmodellen — en linjär process där varje fas slutförs helt innan nästa påbörjas. Den lever kvar i vissa branscher, och att förstå den gör det tydligare *varför* agilt uppstod som en reaktion mot den.

| Sida | Innehåll |
|------|---------|
| Vattenfallsmodellen | Faserna, styrkor och svagheter |
| V-modellen | Vattenfall med test kopplat till varje fas |
